## 怎么玩的

- **真局**:有窗口的房主(`--autohost=N --mode=… --bot --shots=… --shots-every=3 --camera=first|third`,
  16:9 用 `--resolution 1600x900`,4:3 用 `--resolution 1280x960`)加无头机器人(`--autojoin`)。打过的局:
  - 骗子酒馆:3 人越肩 16:9 两局,4 人第一人称 4:3 一局
  - 炸弹猫:4 人越肩 16:9,6 人第一人称 4:3
  - 吹牛骰子:5 人第一人称 4:3,3 人越肩 16:9 两局
  - 斗地主:越肩 16:9 打 3 手,第一人称 16:9 打 2 手 + 1 手
  - 德州长牌:4 人越肩 4:3 打 3 手
  - 每 3–5 秒一张定时截图,拼成 2×2 的联系表逐张看
- **断线**:炸弹猫、斗地主开局后 40 / 50 秒 `kill -9` 一个机器人。房主都正常打完(炸弹猫记「断线离开」,斗地主「牌局提前结束」)。
- **非机器人路径**:临时驱动脚本(`tools/_qa_boot.gd` + `_qa_menu.gd` / `_qa_flow.gd`,不提交)。用 `Input.parse_input_event`
  走了这些:
  - 主菜单:6 个玩法按钮、形象挑选、IP 直连超时与非法地址
  - 说明书:五本书每一页,滚到底再拍一张,16:9 与 4:3 各一遍
  - 开房进等待厅:换形象、Q 快捷语、F1、离开确认
  - 对局中:V 来回切、悬停手牌、G 丢番茄、Q / T、F1 / Esc
  - 结算后点「再来一局」回等待厅
- **悬停大图**:`tools/shot.gd --preview` 在 4:3 下拍骗子酒馆 / 炸弹猫 / 德州的手牌、翻牌行、弃牌堆、摊牌面板。
- **日志**:所有运行日志 grep `SCRIPT ERROR / ERROR / WARNING / leak / ObjectDB`。
  - 唯一的 ERROR 是 IP 直连超时故意触发的 `[debug] FAIL 连接超时`(调试开关打的)。
  - 没有脚本错误,也没有退出泄漏。
- 截图都在 scratchpad `qa/` 下(本文用 `qa/…` 指代)。

## 怎么修的

1. **藏头**(`SeatCamera.update_head`)。原来只在「第一人称坐在座位上」时藏头。现在不论视角,镜头离自己头心不到
   `HEAD_INSIDE`(0.42 m)也藏,出来就露出。这条规则同时管到翻牌机位、开局运镜穿过后脑、探出去的头挡在特写前这几种情况。
   测试:`test_first_person.gd`,翻牌机位在头里就藏、离开就露;原来「翻牌机位露头」的断言改成藏头。
2. **气泡让位**(`WorldLabels`)。
   - `track(..., avoid)`:每帧先按挂点摆好,再让位,从原位重新算,不会越挪越远。
   - 障碍有三类:HUD 的角落面板(`KEEP_OUT_GROUP`)、铭牌、先摆好的气泡。
   - 挪法:先试横挪到最近的空处,横着没地方再往下挪;不出画面,实在没地方就留在原处。
   - 四种牌桌导演的声称气泡、九宫格气泡、快捷语气泡都打开 avoid。
   - 铭牌不让别人,只让开 HUD 面板,而且只往下挪,免得离开自己的头太远。
   - 加进 `KEEP_OUT_GROUP` 的面板:
     - 五种牌桌的左上信息、右上按钮行
     - 德州的摊牌面板
     - 吹牛骰子的开盅面板
     - 斗地主的散局横条
   - 测试:`test_world_labels.gd` 加 6 条,包括让位算法、上缘两个气泡分开、铭牌不动、让开 HUD 面板、铭牌只往下挪。
3. **吹牛骰子开局**。`LiarsDiceScreenState.set_seats` 入座就按每人 5 颗记。「对局结束」只在 `started` 之后才写。测试 1 条。
4. **德州横幅**。导演在 `bets_collected / street / reveal / pot_won` 开头 `set_current(null)`。
   测试在 `test_poker_screen_edges.gd`,改前失败、改后通过。
5. **提示条**。`ToastLayer.clear()`;`main._show_table` 进牌桌时先清掉。测试 `test_toast_layer.gd`。
6. **说明书**。副标题只写「HOUSE RULES」。
7. **调试开关**。
   - `--shots-every=秒`:按真实时间定时截图,逐帧看节奏。
   - `--no-fidget`:截图时机器人不探头。
   - 两个都留着当开发工具。
