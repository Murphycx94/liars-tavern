# 动森式温馨卡通风格(2026-10-08 用户追加)

> 接在视觉改造四个子项目和「Q 版与搞笑表演」之后。用户原话:「可以搞成动森那种风格吗」。
> 只借鉴整体感觉(2 头身、软胶玩具质感、明快粉彩、温馨柔光),不照搬任天堂的任何角色、图案和素材。

## 1. 用户定下的三件事

| 问题 | 选择 |
|---|---|
| 比例 | **动森式 2 头身**:头在现在(1.3 倍)的基础上再放大约 1.5 倍,身子更小更圆、短手短脚、手是没有手指的圆团 |
| 氛围 | **保留夜晚西部酒馆,调亮调软**:还是夜里、暖黄灯光,但整体更亮,阴影更柔、对比更低,颜色换成明快的粉彩暖色,像动森里的室内小店 |
| 脸与质感 | **全面卡通化**:角色和场景、道具都换柔和卡通光照,哑光像软胶玩具;脸简化成动森那样的大眼和小嘴;衣服去掉碎纹理,换纯色或简单印花;家具道具更圆润、颜色更明快 |

## 2. 风格准则(两路共用)

### 2.1 光照模型
- 共用 `src/world/shaders/toon_light.gdshaderinc`(v1 已提交):定义 `light()`,半兰伯特 wrap + smoothstep 软阶,
  暗面留 `toon_shadow`,小而软的高光斑,掠射角边光,BACKLIGHT 照旧。间接光、环境光、反射、SSAO 仍由引擎算。
- 角色(patron / patron_eye)、道具(prop)、木头(wood)、石头(stone)、毡(felt)、贴花(decor)都接这个 include。
  卡牌正面、火焰、粒子、玻璃保持现状(卡面要清楚,火焰是自发光)。
- 参数可按 shader 调(uniform 或 include 前 `#define`),但 `light()` 的接口和结构由场景一路(B)维护;
  角色一路(A)要改光照逻辑时,在自己的 shader 里加参数,不改 include 本体。合并时由协调者统一。

### 2.2 颜色
- 粉彩但不发灰:明度高、饱和度中等;避免纯黑,最暗的颜色也带色相(深棕、深靛)。
- 角色 albedo 上限可以从 0.65 放宽(具体值由 A 定,写进文档);皮毛与脸的线性亮度上限同步放宽。
- 场景:蜂蜜色浅木、奶油色墙、薄荷/青绿毡面、柔红与奶黄点缀;黄铜偏奶黄、少反光。
- 夜晚感保留在:窗外夜空、暖黄灯光的色温、灯下比角落亮。

### 2.3 质感
- 哑光为主:粗糙度普遍偏高(0.6–0.9),金属件也偏缎面。
- 纹理去噪:木纹、灰泥、砖、毛发、布纹的程序噪声降低幅度、放大尺度,远看是干净的色块,近看有一点点手绘感。
- 形体圆润:倒角变大,边角变圆;细碎小件(缝线、小纽扣、小子弹)能删就删,保留能一眼认出角色的标志物。

### 2.4 后期与环境
- 色调映射:对比度降低(adjustment_contrast < 1),饱和略升;ACES 可换 Filmic 或 AgX,以画面为准。
- 环境光提亮,SSAO 半径和强度减小(接触暗部要有,但软),体积雾变淡;泛光柔和,火光不过曝。
- 灯光数量和投影灯数量不变(≤16 盏,投影 3 盏)。

## 3. 角色(A 路)

- 比例:总头部缩放约 1.95(相对最初几何,即 `HEAD_SCALE` 1.3 → 约 1.95,A 以画面为准微调);
  头心仍是 Head 局部 (0, 0.12, 0),瞄准点与机位目标。身子更短更圆(肚子圆)、四肢短粗;
  手改成没有手指的圆团(张开的爪和握拳都是),脚是圆圆的小脚。
- 坐姿:座位高度、桌子高度不变。手仍要能拿牌、拿枪顶到太阳穴(举枪求解按新肩位和臂长重算)。
- 脸:动森式大眼(大椭圆深色瞳孔占眼睛大部分,一大一小两个高光,可选睫毛)、简洁的眉、小嘴(线或 w 形)、腮红;
  眼睛更「画在脸上」而不是凸起的球(降低凸出量);各物种保留眼型差异(猫竖瞳可改成动森式圆瞳加细节,由 A 判断)。
- 衣服:纯色或简单大印花(条纹、格子、圆点放大尺度);去掉缝线、细链、小子弹这类碎件,保留标志物
  (狐狸礼帽和领巾、熊的蝴蝶结和毛巾、猪的工装裤和司机帽、猫的牛仔帽和方巾、乌龟的壳和眼镜、羊驼的编织披带、
  猴子的金边夹克、鳄鱼的子弹带可以简化成一条皮带)。
- 搞笑表演(冒汗、发抖、吐舌、蚊香眼/×眼、星星、得意挑眉、吓一跳、待机小动作)全部保留,按大头重新摆位。
- 要重调的约束(更新测试常量并写明原因,保持原意):HEAD_TOP、BEHIND、羊驼帽顶、名牌高度(含德州铭牌
  7、8 号重叠问题——可以缩小铭牌、错开高度或改挂点,A 决定)、手牌遮挡 ≤5%(必要时调越肩机位)、
  举枪净空、鳄鱼吻尖与探头上限、耳帽间隙、每人 ≤15k 三角形(含椅子)、≤16 个可见网格、≤2 个酒客材质。
- 头像烘焙(species_portraits)和主菜单形象预览跟着调。

### 11.3 改了什么

1. **他人的牌扇立在两爪前方的桌面上空**(原来挂在胸前 `HIP + (0, 0.46, −0.37)`:动森式大头的下巴压着领口、两条手臂平搭在桌沿,胸前没有空地)。
   座位坐标 `FAN_SEAT_POS (0, 0.9, −0.62)`、上仰 `FAN_TILT_DEG −25°`(牌面迎向持牌者,牌背斜朝上给别人看)、`FAN_SCALE 0.9`;
   不跟着前倾转(只跟着身体的蹦跳、侧挪平移),所以前倾、低头、伸爪都碰不到;最低的牌角高出毡面。
2. **低头下限**:总俯仰 ≥ `look_pitch_min − HEAD_DIP_ROOM(0.125)+ (前倾 − SEATED_LEAN)`(前倾越多头越往上抬回来);鳄鱼 `look_pitch_min −0.3 → −0.25`。

3. **探头软碰撞 `ClipGuard`**(`src/world/clip_guard.gd`,TableWorld 持有 `clip_guard`,落座时给每位酒客):

     骗子酒馆立牌、举在头边的牌扇(越肩时自己的)、出价标记。探头目标沿直线截到第一次碰撞之前(`ray_clamp`:只去得了从原位直接看得见的地方,
     不会绕到别人身后卡在缝里),截短后的目标限速 `NECK_GOAL_SPEED 2 m/s` 滑过去,每个积分小步再推出去、去掉往里的速度(贴着边滑,不弹不抖)。
     原位就已经挨着的形状记下差的那一截(slack):不推原位,只是不许更近。
   - 抬:立着的牌扇(自己的、别人的)、烛台、德州公共牌架、骰盅:头按超椭球下沿(指数 8,鳄鱼下颌、羊驼吻的最低点在前面)从上面拱过去,

### 11.4 给吹牛骰子 / 斗地主(及以后的玩法)的接口

- **牌扇**:手里的牌挂到 `Patron.fan` 下(按 `CardTable.fan_slot` / `BombCatLayout.fan_slot` 或自己的扇形排开),默认就立在桌面上空、
  前倾低头碰不到、探头会矮下去、出局会扣在桌上,不用自己摆。`Patron.fan_rest_transform(look)`(纯函数,座位坐标)、`table_fan_transform()`(此刻,含身体平移与倒下)
  可以拿来算飞牌落点。越肩举牌用 `hold_fan(身体局部变换)`,第一人称用 `present_hand_first_person(...)`,放回桌面上空用 `rest_fan()`;
  **不要直接改 `fan.transform`**(每帧会被摆回去)。`fan_mode()` 返回 `FAN_TABLE / FAN_HAND / FAN_FP / FAN_LAP`。
  `set_fan_stowed(on)`:自己举着的牌扇收到桌面上空、矮下去(SeatCamera 每帧按镜头在不在座位上调;`SeatCamera.stow_fan_in_first_person = true`
  让第一人称时也收着——斗地主用,底部的 2D 手牌条才是入口)。
  物种可在 LOOK 里写 `"fan": {"pos", "tilt", "scale"}` 单独调。
- **桌上的道具**:`world.clip_guard.set_prop(id, shape)` / `remove_prop(id)`;shape 用 `ClipGuard.circle(中心, 半径, 顶高, 模式, 节点)`、
  `ClipGuard.rect(中心, 轴向, 半宽, 顶高, 模式, 节点)`、`ClipGuard.box_of(角点, 轴向, 模式, 节点)`;会动的用 `ClipGuard.follow(节点, 半径, 局部点, 模式)`
  (每帧按节点位置取中心、按局部点取顶高)。模式 `BLOCK`(头绕开,高的东西)或 `LIFT`(头从上面拱过去,≤ 桌面上 0.2 米的矮东西);
  给了节点时节点隐藏或释放就自动忽略。吹牛骰子已登记:每只骰盅(`liars_dice_cup_<pid>`,LIFT,跟着盅走)与出价标记(`liars_dice_marker`,BLOCK)。
- **手臂**:新手势要抬手时 `pose_arms(..., clear_face = true)` / `pose_right(..., clear_face = true)`,逐帧摆臂用 `_arm_quat(arm, target, true)`,
  手掌就不会进大头;`hold_paws` 扶道具的不受影响。
- **检查**:`tools/clip_report.gd` 加一个玩法的牌桌只要在 `_neck_worlds` 里加一行;`tests/test_clipping.gd` 有现成的取样写法。

### 11.6 斗地主:身份帽按物种贴合、出牌行让开牌扇

- **身份帽**(用户追加:瓜皮帽、草帽陷进头里、耳朵戳出来)。原来按主颅骨椭球摆,大头的实际表面比主颅骨鼓得多:瓜皮帽几乎整顶埋进头里只露红绒结,
  草帽帽檐压在眼睛上。现在 `DdzHats.FIT` 按物种 × 身份查表(`tools/ddz_hat_fit.gd` 按真实网格生成,帽子 / 物种外观改了就重跑):
  - 大小 `s`、竖向加深 `m`、帽口中心高度 `y`、前后 `z`:从目标大小往下缩,每档先放到刚碰到头(颅骨、眼、眉)再留 4 mm 缝;帽口一圈离下面的头 ≤ 2.5 cm
    (坐在头上,不是飘着;鳄鱼头顶的两个眼包把草帽垫高,4.5 cm);帽顶 ≤ Head 局部 0.7(铭牌 1.92 − 坐直时头枢轴 ≈1.12 − 欢呼蹦起 0.08)。
  - 高耳朵:瓜皮帽缩小、往后挪到两只耳朵后面(猫、羊驼、狐狸、猪、乌龟、鳄鱼也按需往后);草帽在帽檐上开耳洞(狐狸、猪、猫、羊驼):
    `DdzProps.straw_hat(holes)` 的帽檐是极坐标网格,洞里的格子跳过、洞边补立壁与深色包边,按洞缓存(仍是一份网格、一次 draw)。圆耳朵的帽子坐在耳朵上面。
  - 歪戴 `TILT (−6, 0, 5)`(原 −8, 0, 7)。
  - 测试 `tests/test_ddz_hats.gd`:8 物种 × 两顶帽子,走 `DdzHats.put_on`:不碰头、帽口一圈往上看不到头(不埋在头里)、往下离头 ≤ 2.5 cm、不碰耳朵(穿过耳洞不算)、帽顶 ≤ 0.7;
    戴帽后 `head_metrics` 变大、摘帽复原。截图开关 `tools/shot.gd --lineup --ddz-hats=landlord|farmer|mix`。
- **出牌行**:牌扇挪到两爪前方的桌面上空以后,沿世界 X 排开的对手出牌行朝自己那头伸得太远,插进对手的牌扇(130 / 130)。
  `DdzLayout.ROW_RADIUS 0.36 → 0.3`、`ROW_BACK 0.1 → 0.05`,对手一行最宽 `OPP_MAX_ROW 0.36`(本机仍 `MAX_ROW 0.46`);两行之间、与底牌之间仍有空隙。
